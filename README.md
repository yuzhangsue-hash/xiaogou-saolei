# 🐶 扫雷

一个可在电脑和手机浏览器玩的扫雷训练网页。

- 电脑：左键翻开，右键插旗。
- 手机：选择“翻开”或“插旗”后轻触格子。
- 包含初级、中级、高级、撤销、检查旗子和带解释的提示。
- 只提供纯逻辑棋盘：各首击位置的棋盘已提前生成并通过求解器完整通关验证，首次点击可立即开始。若棋盘资源未载入，仍会在后台生成并验证，不会把未经验证的棋盘投入游戏。
- 通关后显示小狗庆祝动画。

求解器使用单数字、区域相减、连通边界 CSP 枚举和全局剩余雷数。旗子不被当作已证实的地雷。运行 `npm test` 可验证核心逻辑。

维护者更改求解器或棋盘生成器后，运行 `node scripts/build-puzzles.cjs` 重新生成预验证棋盘库，并运行 `npm test`。
